# Job Description: ML Platform Engineer

Company: Acme Analytics (Series B data infrastructure company)
Location: Bengaluru, India (Remote-friendly)
Experience Required: 3-6 years

## What you absolutely need

- Production experience operating distributed training and inference infrastructure
  (Kubernetes, Ray, Spark) at meaningful scale.
- Strong Python and solid software engineering fundamentals; you will write and
  review production code daily.
- Hands-on experience with model serving, latency optimization, and inference
  optimization (ONNX, quantization, Triton).

## Nice to have, but we won't reject you for missing it

- Experience with LLM fine-tuning pipelines (LoRA, PEFT).
- Open-source contributions in the MLOps space.

## Logistics

Notice period: we'd love sub-45-day notice.
Candidates in Bengaluru, Chennai, Hyderabad welcome to apply.
We expect candidates to be reachable — a stale profile with a low response rate
is not actually available for hiring purposes.
